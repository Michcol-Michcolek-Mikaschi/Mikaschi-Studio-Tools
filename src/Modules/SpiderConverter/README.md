# Spider Converter

Moduł do konwersji assetów Tibia między wersjami klienta. Przepisanie CLI SpiderClientConverter na C# / Avalonia UI z interfejsem graficznym.

## Funkcje

- Konwersja assetów między wersjami klienta Tibia
- Obsługa formatu Protocol Buffers (Google.Protobuf)
- Interfejs graficzny z formularzem parametrów i logiem operacji
